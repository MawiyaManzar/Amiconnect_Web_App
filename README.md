# AmiConnect Web App

A modern platform designed to connect students across the Amity campus.

## Overview

AmiConnect allows students to discover peers, network, share timetables, browse campus events, and collaborate seamlessly.

## Tech Stack

- **Frontend**: React (Vite, TypeScript, React Router, Zustand, Vanilla CSS)
- **Backend**: Node.js / Express (TypeScript, Drizzle ORM, PostgreSQL)

## Getting Started

### Prerequisites

- Node.js (v18+)
- PostgreSQL database

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MawiyaManzar/Amiconnect_Web_App.git
   cd Amiconnect_Web_App
   ```

2. Setup Backend:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

3. Setup Frontend:
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```
